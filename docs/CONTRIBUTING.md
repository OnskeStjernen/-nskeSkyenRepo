
# Contributing til Ønskestjernen


## Workflow

Vi bruger GitHub til at arbejde sammen om projektet. 
Alle arbejder i det samme repository, men laver deres ændringer i hver deres feature branch.

1. Opret ny feature branch til det du skal arbejde med.
2. Lav dine ændringer, og test at de virker.
3. Commit og push dine ændringer til GitHub.
4. Opret en pull request fra din feature branch til developer branch
5. Få dine ændringer gennemgået, inden pull requesten bliver merged


## Branching Strategi

feature -> developer -> main -> prod

- **feature:** Bruges til at lave nye funktioner eller ændringer. 
- **developer:** Her samles de nye funktioner fra feature branches.
- **main:** Indeholder den version af applikationen, som er klar til at blive merged til prod.
- **prod:** Indeholder den færdige applikation, som er forbundet med Microsoft Azure så den kan ses.


## Coding Guidelines

- Følg Java conventions
- Brug meningsfulde navne til klasser, metoder og variabler
- Undgå at bruge hardcodede værdier


## Pull Requests

- Give den en beskrivende titel.
- Sørge for, at dine ændringer er testet.
- Få ændringerne gennemgået, før de bliver merged.
